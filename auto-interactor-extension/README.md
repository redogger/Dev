# Auto Interactor Pro - Chrome Extension

## 📋 نظرة عامة

إضافة Chrome متقدمة للتفاعل التلقائي مع صفحات الويب. تتيح لك أتمتة المهام المتكررة، استخراج البيانات، ملء النماذج تلقائياً، والمراقبة المستمرة لعناصر الصفحة.

## 🚀 الميزات الرئيسية

### 1. التشغيل التلقائي
- حقن Content Scripts تلقائياً عند تحميل الصفحة
- الاستماع لأحداث التنقل بين الصفحات
- تنفيذ إجراءات مبرمجة مسبقاً دون تدخل المستخدم

### 2. التفاعل مع DOM
- قراءة وتعديل عناصر الصفحة
- محاكاة النقرات (Auto-clicker) مع سلوك بشري
- ملء النماذج تلقائياً
- استخراج البيانات من الصفحة

### 3. الجدولة الزمنية
- استخدام chrome.alarms لتشغيل مهام دورية
- تنفيذ إجراءات في أوقات محددة
- تكرار العمليات بفواصل زمنية مخصصة

### 4. نظام القواعد
- دعم CSS Selectors و XPath
- قواعد قابلة للتخصيص حسب URL
- تأخير قابل للتعديل بين الإجراءات
- خيار "لمرة واحدة فقط"

### 5. المراقبة والتنبيهات
- مراقبة التغيرات في عناصر الصفحة
- إرسال إشعارات عند حدوث تغييرات
- تسجيل جميع الأحداث للتتبع

## 🔧 التثبيت

1. افتح Chrome وانتقل إلى `chrome://extensions/`
2. فعّل "وضع المطور" (Developer mode) في الزاوية العلوية اليمنى
3. انقر على "تحميل إضافة غير مضغوطة" (Load unpacked)
4. اختر مجلد `auto-interactor-extension`
5. ستظهر الإضافة في شريط الأدوات

## 📖 دليل الاستخدام

### إنشاء قاعدة تلقائية

1. انقر على أيقونة الإضافة لفتح الـ Popup
2. أو انتقل إلى صفحة الإعدادات للنقر على "الإعدادات المتقدمة"
3. في تبويب "القواعد":
   - أدخل اسم القاعدة (مثال: "نقر تلقائي")
   - حدد نمط URL (مثال: `*example.com*`)
   - أضف الإجراءات المطلوبة:
     - نوع الإجراء (نقر، ملء، استخراج...)
     - CSS Selector أو XPath للعنصر
     - القيمة (للملء)
     - التأخير بعد الإجراء
4. احفظ القاعدة

### أمثلة على القواعد

#### مثال 1: نقر تلقائي على زر
```json
{
  "name": "نقر على زر التسجيل",
  "urlPattern": "*example.com/register*",
  "delay": 2000,
  "actions": [
    {
      "type": "click",
      "selector": "#submit-btn",
      "delayBetween": 500
    }
  ]
}
```

#### مثال 2: ملء نموذج تلقائياً
```json
{
  "name": "ملء نموذج الاتصال",
  "urlPattern": "*contact*",
  "delay": 1000,
  "actions": [
    {
      "type": "fill",
      "selector": "#name",
      "value": "أحمد محمد",
      "delayBetween": 300
    },
    {
      "type": "fill",
      "selector": "#email",
      "value": "ahmed@example.com",
      "delayBetween": 300
    },
    {
      "type": "click",
      "selector": "#send-btn",
      "delayBetween": 0
    }
  ]
}
```

#### مثال 3: استخراج بيانات
```json
{
  "name": "استخراج أسعار المنتجات",
  "urlPattern": "*shop*",
  "delay": 3000,
  "actions": [
    {
      "type": "extract",
      "selector": ".price",
      "options": {
        "extractType": "text"
      }
    }
  ]
}
```

### أنماط URL المدعومة

- **نمط بسيط**: `example.com` - يتطابق مع أي URL يحتوي على النص
- **نمط مع wildcard**: `*example.com*` - يتطابق مع أي URL يحتوي على example.com
- **Regular Expression**: `/.*example\\.com\\/products.*/` - نمط Regex كامل

## 🔐 الأمان والخصوصية

### أفضل الممارسات المُطبقة:

1. **الحد الأدنى من الصلاحيات**: طلب فقط الصلاحيات الضرورية
2. **عدم تخزين بيانات حساسة**: لا يتم تخزين معلومات شخصية
3. **التشفير**: البيانات الحساسة مشفرة في التخزين
4. **الشفافية**: جميع الصلاحيات موضحة في manifest.json
5. **التحكم الكامل**: يمكن للمستخدم تعطيل الإضافة في أي وقت

### الصلاحيات المطلوبة:

| الصلاحية | السبب |
|----------|-------|
| `tabs` | التحكم في التبويبات وتنفيذ الإجراءات عليها |
| `scripting` | حقن السكريبتات في الصفحات |
| `storage` | حفظ الإعدادات والقواعد |
| `webNavigation` | مراقبة التنقل بين الصفحات |
| `alarms` | جدولة المهام الدورية |
| `host_permissions` | التفاعل مع جميع المواقع |

## 🛠️ التطوير

### متطلبات التطوير:
- Node.js (اختياري)
- Chrome Browser

### اختبار الإضافة:

1. افتح `chrome://extensions/`
2. فعّل وضع المطور
3. انقر على "Inspect views: background page" لفتح DevTools للـ Service Worker
4. استخدم Console لتتبع الرسائل والأخطاء

### Message Passing Example:

```javascript
// من Content Script إلى Background
chrome.runtime.sendMessage({
  action: 'executeAction',
  actionData: {
    type: 'click',
    selector: '#button'
  }
});

// من Background إلى Content Script
chrome.tabs.sendMessage(tabId, {
  action: 'executeRule',
  rule: ruleData
});
```

## ⚠️ تحذيرات هامة

1. **احترام شروط الخدمة**: تأكد من أن الاستخدام التلقائي مسموح به في الموقع المستهدف
2. **تجنب الإفراط**: لا تفرط في استخدام الأتمتة لتجنب الحظر
3. **الاختبار**: اختبر القواعد على صفحات تجريبية أولاً
4. **النسخ الاحتياطي**: قم بتصدير الإعدادات بانتظام

## 🐛 استكشاف الأخطاء

### المشكلة: الإضافة لا تعمل
**الحل**: 
- تأكد من تمكين الإضافة في `chrome://extensions/`
- تحقق من أن الصفحة تسمح بحقن السكريبتات
- راجع Console للأخطاء

### المشكلة: القواعد لا تُنفذ
**الحل**:
- تحقق من نمط URL
- تأكد من صحة CSS Selector
- راجع السجلات في تبويب "السجلات"

### المشكلة: العناصر لا تُوجد
**الحل**:
- استخدم XPath بدلاً من CSS Selector
- زد قيمة التأخير قبل التنفيذ
- تحقق من أن العنصر موجود عند التنفيذ
